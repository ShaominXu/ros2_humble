# ROS 2 Humble 源码解读：写作项目

## 目标与读者

暂定书名：《ROS 2 Humble 源码解读：从节点到通信与执行》。

源码基线由项目作者确定为当前工作区。书稿直接解读这份源码，不以其他版本替换；后续记录版本信息用于复现与追溯，不作为开始写作的前置门槛。

面向已经使用过 ROS 2、具备 C++ 基础，希望理解框架内部机制的读者。目标是形成能够逐章阅读、复现实验、追溯源码依据的书稿。读者定位和书名均可调整。

以 C++ 客户端库为主线，沿示例 → rclcpp → rcl → rmw → DDS 展开；Python 客户端库作为独立对照章节。中间件先选择一个具体实现深入，再说明抽象接口与其他实现的差异。

## 内容边界

第一版集中讲解节点、接口生成、发布订阅、执行器、服务、动作、参数、生命周期、组件和启动机制。rosbag2、TF2 作为框架应用案例。RViz、感知、导航和仿真算法暂不作为深入解读对象，可在后续扩展。

## 源码与证据规则

- 本工作区是阅读素材；目录名和发行版默认值不能证明所有源码版本都属于同一 Humble 快照。
- 正式写作前记录各相关仓库的来源、分支或标签、提交号和本地修改。若缺少版本信息，明确记录未知，不能补写猜测值。
- 章节引用使用“仓库 + 相对路径 + 类或函数 + 提交号”；行号仅用于辅助定位。
- 区分源码事实、设计解释和实验观察。尚未运行的实验标记为待验证。
- 调用链注明适用条件，例如跨进程、进程内、借用消息、具体 RMW 实现。
- 摘录必要的短代码并附来源；以自己的解释与图示为主体。

## 每章交付

每章包含问题引入、最小示例、架构图或时序图、关键调用链、源码分析、可复现实验、边界条件和小结。使用 [章节模板](chapter-template.md) 写作，按 [全书目录](outline.md) 组织。

书稿保存为 Markdown，图示优先保存为可维护的文本源，实验代码与步骤独立保留。待试写章节稳定后，再确定 PDF 或其他出版格式的排版工具。
