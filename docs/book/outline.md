# 全书目录草案

本目录用于组织解读，章节标题和拆分可在试写后调整。

## 导读

[源码全景与阅读路线](introduction.md)：项目范围、目录与模块职责、核心分层和章节阅读入口。

## 第一篇：建立源码阅读地图

1. 工作区、包与版本基线：源码范围、package.xml、构建依赖与运行环境。
2. 从 talker/listener 追踪一条消息：串联创建、发布、接收与回调，建立全书问题地图。
3. ROS 2 分层与资源生命周期：rclcpp、rcl、rmw、DDS 的职责与对象关系。

## 第二篇：节点与消息的诞生

4. 初始化、Context 与 Node：节点接口、上下文、创建和销毁。
5. 消息定义如何变成代码：rosidl 解析、生成器、类型支持与序列化入口。
6. Publisher 与 Subscription：对象创建、普通跨进程 publish/take 路径与错误处理。
7. QoS 与通信发现：配置传递、兼容性、发现过程与验证方法。

## 第三篇：事件如何成为回调

8. WaitSet、GuardCondition 与 Timer：等待、唤醒、就绪与取出事件。
9. Executor 与 CallbackGroup：单线程、多线程、回调选择和并发约束。
10. 进程内通信与消息所有权：路径切换、复制、移动与生命周期。
11. 借用消息与内存管理：接口条件、实现支持与性能实验边界。

## 第四篇：更丰富的交互机制

12. Service 与 Client：请求、响应、Future 和执行器之间的关系。
13. Action：目标、反馈、结果与取消的协作过程。
14. 参数：声明、校验、参数服务与事件。
15. 生命周期节点：状态机、转换回调与资源管理。
16. 组件：注册、插件加载、容器和执行器。
17. rclpy 对照：Python 接口、底层绑定和回调执行。

## 第五篇：机制在工程中的应用

18. launch 与 launch_ros：描述、动作、事件和进程编排。
19. ros2cli：命令扩展、图查询与诊断入口。
20. rosbag2：订阅、存储插件、录制和回放。
21. TF2：变换缓存、查询与消息接入。
22. 一次完整排障：从现象、实验到源码证据。
