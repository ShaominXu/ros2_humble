# 全书目录草案

章节安排可随试写调整。

## 阅读路线与分析范围

章节按前置知识展开：建立地图 → 建立通信对象 → 理解交付与调度 → 扩展交互机制 → 综合应用。

- 第 1–9 章构成基础主线，建议顺序阅读。
- 第 10–11 章深入通信与内存管理，在基础主线之后阅读。
- 第 12–21 章按问题选读；Service 是 Action 和参数服务的前置知识，组件是理解组件容器启动的前置知识。
- 第 22 章串联现象、对照实验、调用链与源码证据。

主线沿示例 → rclcpp → rcl → rmw 展开，具体中间件以 `rmw_fastrtps_cpp` 和 Fast DDS 的关键路径为例。进入 DDS 时注明所追踪的实体或函数及停止位置；其他 RMW 按必要差异对照，结论注明实现和配置条件。

第 2 章建立端到端问题地图，后续章节按职责拆解，通过交叉引用减少重复。实验从可观察的问题出发，分别记录配置、预期现象、实际观察、证据位置和结论边界；未执行的实验保持待验证。

## 导读

## 第一篇：建立源码阅读地图

1. 工作区、包与版本基线：源码范围、package.xml、构建依赖与运行环境。
2. 从 talker/listener 追踪一条消息：串联创建、发布、接收与回调，建立全书问题地图。
3. ROS 2 分层与资源所有权：各层职责、对象持有关系与释放依赖；初始化细节见第 4 章，生命周期节点状态机见第 15 章。

## 第二篇：节点与消息的诞生

4. 初始化、Context 与 Node：节点接口、上下文、创建和销毁。
5. 消息定义如何变成代码：rosidl 解析、生成器、类型支持与序列化入口。
6. Publisher 与 Subscription：对象创建、普通跨进程 publish/take 路径与错误处理；等待与回调调度留到第 8–9 章。
7. QoS 与通信发现：分别分析发现与端点匹配、QoS 配置与兼容性，再用图信息和样本记录验证。

## 第三篇：消息交付、回调执行与内存管理

8. WaitSet、GuardCondition 与 Timer：等待、唤醒、就绪与取出事件。
9. Executor 与 CallbackGroup：单线程、多线程、回调选择和并发约束。
10. 进程内通信与消息所有权：路径切换、复制、移动与生命周期。
11. 借用消息与内存管理：接口条件、实现支持与性能实验边界。

第 8 章解释等待、唤醒与就绪，第 9 章解释工作选择、取出和回调执行。第 10–11 章统一比较启用条件、实际路径、所有权、复制位置、实现限制与实验，并区分进程内通信、借用消息、共享内存和零拷贝。
