# 附录 D 术语、参考入口与代码来源

## D.1 术语表

| 术语 | 本书含义 |
| --- | --- |
| 工作区 | 汇集源码、构建和安装产物的环境，可包含多个仓库与包 |
| 仓库、包 | 仓库是版本管理单位，包是 ROS/ament 构建和分发单位 |
| Context | 一组初始化、关闭和有效性状态；不是执行器线程 |
| Node interface | 节点能力的接口拆分，如 topics、timers、parameters |
| RMW | rcl 与具体中间件实现之间的接口边界 |
| 类型支持 | 将接口类型连接到序列化和具体通信实现的代码与句柄 |
| 发现 | 获取节点与端点存在信息的过程，不等于样本交付 |
| QoS offered/requested | 发布端提供与订阅端要求的策略关系 |
| WaitSet | 收集实体并等待就绪的结构，不执行所有用户回调 |
| GuardCondition | 唤醒等待的条件，不携带普通话题样本 |
| Executor | 等待、选择和执行工作的调度对象 |
| CallbackGroup | 限制一组回调的并发许可；不自动管理用户后台线程 |
| Future、promise | 异步完成状态及其写入端；等待 Future 不必然推进 ROS 调度 |
| Waitable | 将复合或自定义等待实体接入执行器的抽象 |
| 进程内通信 | 同一进程中受配置约束的消息交付路径 |
| 借用消息 | 带借出、发布与归还规则的资源接口，可能本地分配回退 |
| 共享内存 | 一种内存访问或传输机制，不等同于进程内通信 |
| 零复制 | 必须声明测量边界的性能描述，不能由接口名称直接推断 |
| GoalHandle | 一个 Action 目标的操作与状态句柄 |
| Lifecycle | 节点管理状态协议，与一般 C++ 对象存活期不同 |
| Component | 可经工厂创建并加载到容器中的节点实现 |
| Launch Action | 启动系统执行的动作，与 ROS Action 协议不同 |
| Substitution | 根据 launch 上下文求值的描述对象 |
| SerializedMessage | 序列化字节的消息包装，不是应用的普通类型化消息 |
| TF frame | 坐标系标识；变换查询还需方向与时间 |
| transient-local | 发布端存活期间可向晚加入的兼容订阅端提供保留历史的持久性策略 |

## D.2 参考材料的使用顺序

先阅读章内指向本地的示例、核心库和具体实现，再使用 [固定源码清单](../../sources.repos) 定位上游仓库的对应提交。源码是本书机制判断的主要证据；文档用于补充安装、概念和接口说明，更新后的文档不能无条件替代固定快照。

第 1 章和仓库 README 提供安装入口。需要版本迁移或其他 RMW 行为时，应重新核对实现，另记差异。本轮没有把外部文档中的最新行为写成本地实测结果。

## D.3 代码来源

`src/` 下源码来自固定清单列出的上游仓库，版权与许可证以原文件为准。章内链接和必要短摘录用于定位与解释，不改变原项目许可证。

`experiments/` 保存本书探针和启动示例；它们用于观察指定机制，不作为完整生产实现或性能基准。新建的 launch 示例在第 18 章说明用途与限制。实验产物和日志应注明运行环境，源码文件存在不代表已经编译运行。
