## C.1 一次实验的记录格式

记录编号、执行日期、源码提交、环境加载来源、完整命令、配置变量、预期、实际结果和证据路径。对照实验明确唯一改变的变量；需要多项改变时另建实验编号。

日志与 bag 建议保存到仓库根目录 `experiment-results/`，但本书不提交虚构的结果文件。已有目录应保留并给新记录另起名字。调试器记录注明符号、线程暂停模式、断点和栈；报告中区分程序行为与断点造成的暂停影响。

## C.2 从待执行到已核验

只有命令实际执行、结果已保存、预期与实际差异已解释后，才能把对应实验标为已核验。运行失败也应保存记录：缺依赖、插件不可用、没有发现、配置不兼容和程序异常分别处理，不能统一写成“ROS 不工作”。

静态检查可以核实链接、语法和源码分支，不能代替消息传输、资源归还与时序观察。性能结论还需可重复测量方法、负载条件和统计口径。
